«Чудо Обувь» — пробный экзамен. Пошаговая инструкция
===================================================

Состав папки chudo_obuv:
  БД_скрипт.txt      — SQL-скрипт: создание базы (3НФ) и загрузка всех данных из Excel
  Excel_3НФ.xlsx     — те же данные из Excel, приведённые к 3НФ (один лист = одна таблица)
  app.py             — приложение на Python (tkinter + pymysql)
  logo.png           — логотип «Чудо Обувь» из ресурсов задания
  ИНСТРУКЦИЯ.txt, ОБЪЯСНЕНИЕ_КОДА.txt


ЧАСТЬ 1. Как Excel приведён к 3 нормальной форме
-------------------------------------------------
1. Во все таблицы добавлен первичный ключ id (AUTO_INCREMENT).
2. Повторяющиеся значения вынесены в справочники, в основных таблицах
   вместо текста хранится внешний ключ (..._id):
     Products_import:  Категория     -> categories    (products.category_id)
                       Подкатегория  -> subcategories (products.subcategory_id)
                       Производство  -> manufacturers (products.manufacturer_id)
     Users_import:     Роль          -> roles         (users.role_id)
     Sizes_import:     Размер        -> sizes
     Stock_Items_import: товар и размер хранятся как product_id и size_id,
                       таблица stock = остаток конкретного товара конкретного размера.
3. В stock удалены полные дубли (например, товар 8 / размер 6 был записан 4 раза)
   и добавлено ограничение UNIQUE (product_id, size_id). Если у пары товар+размер
   было два разных количества, оставлено первое.
4. Размеры: id 1–29 взяты из таблицы соответствия на листе Stock_Items_import
   (на них ссылаются остатки), остальные размеры из Sizes_import добавлены
   после них (id 30–35).
5. Роли пользователей взяты из столбца E листа Users_import сверху вниз
   (20 значений на 20 пользователей; 1 — Администратор, 2 — Менеджер,
   3 — Авторизованный пользователь).
6. В Excel нет паролей, поэтому в таблицу users добавлен столбец password,
   у всех пользователей пароль пустой: вход только по логину, поле
   «Пароль» в приложении оставляется пустым.
7. Orders_import: одна строка Excel = один товар в заказе. Данные разделены
   на две таблицы:
     orders      — шапка заказа (номер, дата, клиент) — хранится один раз;
     order_items — строки заказа (товар, размер, количество, цена за единицу).
   ФИО -> users (orders.user_id), размер -> sizes (order_items.size_id,
   в Excel указан сам размер, например 38, он заменён на id размера).
   Столбцы «Категория» и «Производство» из заказов удалены: они уже есть у
   товара в products и зависят от товара, а не от заказа (транзитивная
   зависимость — нарушение 3НФ). «Цена за единицу» оставлена в order_items,
   так как это цена на момент продажи, она отличается от текущей цены товара.

Итоговые таблицы:
  roles(id, name)
  users(id, last_name, first_name, patronymic, login, password, role_id)
  categories(id, name)
  subcategories(id, name)
  manufacturers(id, name)
  products(id, name, category_id, subcategory_id, manufacturer_id, image, description, composition, price)
  sizes(id, size)
  stock(id, product_id, size_id, quantity)
  orders(id, order_date, user_id)
  order_items(id, order_id, product_id, size_id, quantity, price)


ЧАСТЬ 2. Разворачивание базы данных в MySQL Workbench
------------------------------------------------------
1. Запустить MySQL Workbench.
2. На главном экране нажать на подключение «Local instance MySQL»
   (localhost:3306), ввести пароль пользователя root.
3. Открыть файл БД_скрипт.txt в Блокноте, нажать Ctrl+A, Ctrl+C.
4. В Workbench: File -> New Query Tab (или Ctrl+T).
5. Вставить скрипт в окно запроса (Ctrl+V).
6. Выполнить весь скрипт: кнопка с молнией «Execute» (или Ctrl+Shift+Enter).
   Скрипт сам удаляет старую базу chudo_obuv (если была), создаёт новую,
   создаёт таблицы и заполняет их данными.
7. В панели Navigator (слева, вкладка Schemas) нажать значок «обновить» —
   появится база chudo_obuv.
8. Проверка: выполнить запросы
     SELECT * FROM chudo_obuv.products;   -- 31 строка
     SELECT * FROM chudo_obuv.users;      -- 20 строк
     SELECT * FROM chudo_obuv.orders;     -- 10 строк
9. ER-диаграмма (если нужна): Database -> Reverse Engineer -> выбрать
   подключение -> Next -> отметить chudo_obuv -> Next ... -> Finish.
   Сохранить через File -> Export -> Export as PNG.


ЧАСТЬ 3. Запуск приложения на Python
------------------------------------
1. Установить Python 3 (при установке отметить «Add Python to PATH»).
   tkinter входит в стандартную поставку Python.
2. Открыть командную строку (Win+R -> cmd) и установить драйвер MySQL:
     pip install pymysql
3. Открыть app.py в редакторе и в строке DB указать свои настройки,
   прежде всего пароль root от MySQL:
     DB = dict(host="localhost", port=3306, user="root", password="root", ...)
   Если MySQL работает на другом порту — заменить 3306.
4. Перейти в папку с решением (важно: logo.png должен лежать рядом с app.py):
     cd путь\к\chudo_obuv
5. Запустить:
     python app.py
6. Проверка входа (ввести логин, поле «Пароль» оставить пустым):
     isivanov  — Администратор (видны кнопки «Добавить товар» и «Заказы»)
     papetrov  — Менеджер      (видна кнопка «Заказы»)
     asidorova — Авторизованный пользователь (только список товаров)
     «Войти как гость» — вход без логина, только список товаров.
   Неверный логин/пароль -> окно «Ошибка входа».
   Неверный пароль от MySQL или не запущен сервер -> окно «Ошибка подключения».
7. Кнопка «Выход» возвращает на окно входа. Кнопка «Заказы» открывает список
   заказов из базы, «Назад» возвращает к товарам. Кнопка «Добавить товар» —
   заглушка (показывает сообщение «В разработке»).
